# Mechanical Structure

## Folder Structure

> **Body**  
>
> It refers to the upper structure. Body mainly mounts stepper motor, water pump and vice board.
>
> **Chassis**
>
>  chassis directly mounts all BLDCs and PCB boards except vice board.
>
> **Connection**
>
> The part that connects the body and chassis.
>
> **Assembly**
>
> Assembly is the set that includes body, chassis, connection, Mecanum wheels and all PCB boards with wire connecting them together.
