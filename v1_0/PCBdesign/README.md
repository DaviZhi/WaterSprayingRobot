# PCB Design
## Folder Structure
> **ChassisMotor**  
Power supply of four BLDCs, using XL6019 as power management.  
> **CircuitSupply**  
Mainstream of all modules, it directly connects with battery.  
> **MasterCore**  
This folder actually contains two PCB boards: MasterCore and ViceCore. Including necessary external circuit.  
> **StepperMotor**  
Driver(DRV8825) and power supply(XL6019) of stepper.  
> **WaterPump**  
Driver(DRV8870) and power supply(TPS5430) of water pump.  
> **Gerber**  
PCB fabrication files.
